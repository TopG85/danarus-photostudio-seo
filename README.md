# Danarus Photostudio — Website & SEO Project

Tracking website fixes and Google visibility improvements for [danarusphotostudio.co.uk](https://www.danarusphotostudio.co.uk), a Manchester-based wedding photography business built on Hostinger AI Website Builder.

## Background

The client reported that his website wasn't "searchable" and wasn't producing results in Google rankings. Initial investigation found:

- The site **is indexed** by Google (appears when searching the business name directly)
- The homepage text is heavily **keyword-stuffed** (e.g. "affordable wedding photographer" repeated many times), which can actively hurt rankings rather than help
- No clear heading structure (H1/H2) on the page
- Outdated elements (Google+ icon, ©2014 copyright date)
- Unconfirmed whether Google Search Console is connected to the website domain
- Unconfirmed whether a Google Business Profile exists (conflicting info — needs client confirmation)
